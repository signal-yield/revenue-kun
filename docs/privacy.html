Privacy Policy

Last updated: 2026-07-14

Overview

revenue-kun is a local-first open-source software project for processing rent-roll CSV files and text-based PDF files. It is not a hosted SaaS product. The software runs in the user's own local environment.

Local Processing

CSV and PDF files selected by the user are processed locally by revenue-kun. revenue-kun itself does not transmit uploaded input files to an external server. The Local Web UI is designed to bind only to 127.0.0.1 and is not intended for internet or LAN exposure.

No Accounts, API Keys, Cookies, or Telemetry

revenue-kun does not require API keys, external account linking, or hosted user accounts. The current project does not include application telemetry, usage analytics, tracking pixels, or cookies.

Network Activity Outside revenue-kun Processing

Normal development and installation workflows may involve network access outside the revenue-kun application itself, such as dependency downloads, Git clone or fetch operations, Docker image builds, or the user's own use of third-party services. Information that a user independently provides to a third-party service is governed by that third party's terms and privacy policy.

Repository Data

The public repository is intended to contain only synthetic sample data. Private PDFs, real property information, API keys, secrets, temporary generated Excel files, logs, and cache files should not be committed.

Contact

For privacy questions, open an issue at https://github.com/signal-yield/revenue-kun/issues.
