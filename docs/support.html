Support

revenue-kun support is handled through GitHub Issues: https://github.com/signal-yield/revenue-kun/issues.

Bug Reports

When reporting a reproducible bug, include the revenue-kun version, operating system, Python version, the command or workflow used, whether the input was CSV or a text-based PDF, the expected behavior, and the actual error or output. If a sample file is needed, attach only synthetic or safely redacted data.

Security Issues

Do not post security-sensitive details, secrets, private documents, or exploitable vulnerability details in a public issue. Open a minimal GitHub Issue requesting a private coordination channel, or contact the maintainer through the repository owner profile.

Support Scope

Supported topics include installation, Local Web UI startup on 127.0.0.1, CSV or text-based PDF processing, and generated workbook behavior. Unsupported topics include OCR, scanned PDFs, smartphone-captured images, hosted SaaS operation, real-estate appraisal, investment advice, legal advice, and tax advice.

Please do not attach private PDFs, real property information, API keys, secrets, temporary generated Excel files, logs, or other confidential data to public issues. Use synthetic or redacted sample files when reporting reproducible problems.
