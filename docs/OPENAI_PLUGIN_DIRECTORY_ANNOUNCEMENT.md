## PR TIMES差し込み文

不動産収益試算OSS「revenue-kun」v0.5.2がOpenAI Plugins Directoryで公開されました。ChatGPTのプラグイン画面で `revenue-kun` を検索して追加できます。本ツールはレントロールCSVまたはテキスト抽出可能PDFから、計算過程を確認できる直接還元法Excelをローカル環境で生成します。

revenue-kunの出力は収益試算値であり、不動産鑑定評価や投資・法律・税務助言ではありません。OCR、スキャンPDF、スマートフォン撮影画像、ホスティング型SaaSには対応していません。
